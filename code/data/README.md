# Data

This directory stores local working samples for the moRAG prototype.

## Primary Dataset

- Source: `sutro/synthetic-customer-support-dialogues-20k`
- URL: https://hf.co/datasets/sutro/synthetic-customer-support-dialogues-20k
- Split: `default/train`
- License: MIT

## Local Files

- `datasets/sutro_customer_support/raw/sutro_customer_support_sample_100.json`
  - Compact 100-row sample used for initial moRAG development.
- Generated by `../scripts/data/download_hf_sample.py`.
  - Contains only the columns selected in `../configs/datasets/sutro_customer_support.toml`.

- `runs/<dataset_slug>/<run_id>/`
  - Run-scoped processed cases, memory outputs, indexes, answer outputs, and judge results.
  - Use `--run-id` to keep multiple runs for the same dataset.

## Regenerate Sample

Run from the `code/` directory:

```powershell
python -m scripts.data.download_hf_sample
```
