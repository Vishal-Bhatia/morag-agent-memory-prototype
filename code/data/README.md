# Data

This directory stores local working samples for the moRAG prototype.

## Primary Dataset

- Source: `sutro/synthetic-customer-support-dialogues-20k`
- URL: https://hf.co/datasets/sutro/synthetic-customer-support-dialogues-20k
- Split: `default/train`
- License: MIT

## Local Files

- `runs/sutro_customer_support/<run_id>/processed/sutro_customer_support_sample_100.json`
  - Compact 100-row sample used for initial moRAG development.
  - Generated by `../scripts/data/download_hf_sample.py`.
  - Contains only the columns selected in `../configs/datasets/sutro_customer_support.toml`.

- `../../datasets/sutro_customer_support/raw-data/sutro_customer_support_train_raw.xlsx`
  - Full raw local copy of `sutro/synthetic-customer-support-dialogues-20k` for manual inspection.
  - Excluded from Git.
  - Dataset license: MIT.
  - Current local file has 20,000 rows.

- `../../datasets/sutro_customer_support/annotation/cycle-1/sutro-customer-support_annotated_v0.75.xlsx`
  - Annotated Sutro working file.
  - Sheet `data` currently has 19,987 valid rows and 15 rows marked invalid.
  - Valid rows have `validity = yes` and populated `product_category` / `product_subcategory` fields.
  - Excluded from Git.

- `runs/<dataset_slug>/<run_id>/`
  - Run-scoped processed cases, memory outputs, indexes, answer outputs, and judge results.
  - Use `--run-id` to keep multiple runs for the same dataset.

- `../../datasets/tobi_customer_support/raw/tobi_customer_support_train_raw.parquet`
  - Full raw local copy of `Tobi-Bueck/customer-support-tickets`.
  - Excluded from Git.
  - Dataset license: CC-BY-NC-4.0.
  - Current local file has 61,765 rows: 28,261 English and 33,504 German tickets.

## Regenerate Sample

For the annotated Sutro experiment, the main workflow has three pipeline commands.

Run from the `code/` directory:

```powershell
python -m scripts.pipelines.build_experiment_data
python -m scripts.pipelines.build_reference_layer
python -m scripts.pipelines.build_morag_layer
```

Pipeline 1 writes:

- `data/runs/sutro_customer_support/<run_id>/processed/annotated_valid_cases_v0.75.json`
- `data/runs/sutro_customer_support/<run_id>/processed/morag_experiment_sample_1200.json`
- `data/runs/sutro_customer_support/<run_id>/processed/experience_cases.json`
- `data/runs/sutro_customer_support/<run_id>/processed/reference_background_cases.json`
- `data/runs/sutro_customer_support/<run_id>/processed/eval_cases.json`
- `data/runs/sutro_customer_support/<run_id>/processed/split_metadata.json`

Pipeline 2 builds the policy-like `reference_rag` store and the separate past-conversation fallback store.

Pipeline 3 builds moRAG memories from experience cases only, reviews/deduplicates them, and indexes the moRAG store.

The pipeline defaults are configured in `../configs/experiment_config.toml` under `[pipeline]`.

The older Hugging Face sample downloader is still available for compact smoke tests:

```powershell
python -m scripts.data.download_hf_sample
```
